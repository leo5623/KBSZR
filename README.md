# KBSZR
短视频创作者效率提升工具，聚焦文案提取、多平台分发、数字人视频制作三大核心痛点，通过四层架构（UI 层、业务编排层、模型层、浏览器自动化层）构建全流程自动化流水线。采用 Gradio 4.0 与 PyQt6 搭建赛博朋克双主题 UI，依托 asyncio、Playwright 等技术实现异步处理与浏览器自动化，集成 Ollama、Whisper、Voicebox 等本地开源模型及多云端 API，支持抖音、快手、小红书等多平台视频文案提取、多 Provider 路由改写、多引擎配音生成、数字人渲染、后期处理及矩阵分发。当前项目已完成文案提取框架、Cookie 管理、多 Provider 路由及基础 UI 架构搭建，数字人渲染集成与矩阵分发机制处于推进中，视频合成流水线及自动化测试覆盖仍需完善。
